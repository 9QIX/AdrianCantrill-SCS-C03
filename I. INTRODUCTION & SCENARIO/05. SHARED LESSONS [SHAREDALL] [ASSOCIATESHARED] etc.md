# Shared Lesson Labels and Study Strategy

## Overview

Labels such as `[SHAREDALL]` identify material reused across courses. A shared label describes course organization; it does not reduce the topic's SCS-C03 relevance.

## Exam Alignment

- **Primary SCS-C03 Domain:** Security Foundations and Governance
- **Secondary Domain(s):** None
- **Main AWS Services:** None
- **Lesson Type:** Text-Based Reference
- **Exam Importance:** Supporting
- **Core Skill:** Decide whether prior mastery is sufficient to skip repeated foundational material.

## Study Guidance

- Study the lesson if the topic is new.
- Review it if recall is incomplete or service behavior may have changed.
- Skip only when you can explain the concept, design tradeoffs, failure modes, and exam distinctions without prompts.
- Use self-check questions and hands-on validation as evidence of mastery.
