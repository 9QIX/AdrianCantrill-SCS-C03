# Optional Course Email Updates

## Overview

This administrative lesson explains how to opt in to course-platform emails. Email preferences are unrelated to AWS security configuration or the SCS-C03 exam.

## Exam Alignment

- **Primary SCS-C03 Domain:** Security Foundations and Governance
- **Secondary Domain(s):** None
- **Main AWS Services:** None
- **Lesson Type:** Text-Based Reference
- **Exam Importance:** Supporting
- **Core Skill:** Manage optional course communication preferences.

## Workflow

1. Open the course-platform profile settings.
2. Review the email or marketing preference.
3. Enable it only if updates are wanted.
4. Revisit the setting later to change consent.

Use a unique password and multi-factor authentication when the platform supports them. Do not reuse AWS credentials.

## Quick Review

- Email updates are optional.
- The setting belongs to the course platform, not AWS.
- Avoid credential reuse across learning and cloud accounts.
- Treat unexpected course emails and links cautiously.
- This lesson has no direct exam objective.

## Self-Check Questions
