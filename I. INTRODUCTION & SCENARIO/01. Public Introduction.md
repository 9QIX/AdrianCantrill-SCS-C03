# AWS Certified Security – Specialty Course Orientation

## Overview

This course develops the security architecture, implementation, detection, response, governance, identity, and data-protection skills assessed by AWS Certified Security – Specialty. The original introduction targeted SCS-C02; these notes organize its technical objectives under SCS-C03.

## Exam Alignment

- **Primary SCS-C03 Domain:** Security Foundations and Governance
- **Secondary Domain(s):** None
- **Main AWS Services:** AWS security services broadly
- **Lesson Type:** Text-Based Reference
- **Exam Importance:** Supporting
- **Core Skill:** Understand the scope of security-specialty study and apply current SCS-C03 terminology.

## Core Concepts

- Security design starts with business requirements, data classification, threats, and the AWS shared responsibility model.
- The exam expects service selection plus reasoning about prevention, detection, investigation, response, and recovery.
- Encryption, identity, logging, network protection, and governance are connected controls rather than isolated topics.

## Memory Hooks

### One-Line Memory Hook

> **Protect, detect, respond, govern—and be able to explain why each control fits.**

## Quick Review

- Use the current SCS-C03 domains when organizing study.
- Learn policy evaluation and service boundaries, not console-click sequences.
- Distinguish preventive, detective, and responsive controls.
- Tie every technical choice to risk and operational requirements.
- Prefer current official AWS documentation when behavior may have changed.
