# Practice Review 3: Guardrails, Network Evaluation, and Automated Security

## Overview

The final practice set focuses on organization guardrails, private CloudFront delivery, stateful and stateless network controls, Amazon EBS encryption, automated IP blocking, IAM roles for workloads, event-driven notification, role assumption, and KMS key-material rotation. The original quiz remains the assessment; these notes capture its technical decision points.

## Exam Alignment

- **Primary SCS-C03 Domain:** Infrastructure Security
- **Secondary Domain(s):** Identity and Access Management, Data Protection, Detection
- **Main AWS Services:** AWS Organizations, Amazon VPC, Amazon CloudFront, AWS WAF, Amazon EBS, AWS KMS, AWS IAM, Amazon EventBridge, Amazon SNS
- **Lesson Type:** Text-Based Reference
- **Exam Importance:** High
- **Core Skill:** Determine which layer owns a control and combine preventive, detective, and response components correctly.

## Knowledge Connectors

- An AWS Organizations service control policy restricts maximum permissions in member accounts, including their root users, but does not restrict the management account.
- CloudFront signed URLs are suited to individual objects or clients; signed cookies can authorize access to multiple restricted objects. Secure the origin separately with OAC and an S3 bucket policy.
- Security groups are stateful, resource/ENI-associated allow controls. Network ACLs are stateless, subnet-associated allow/deny controls with ordered rules.
- Amazon EBS encryption protects volume data at rest, snapshots created from the volume, and data moving between the volume and its attached instance.
- A managed IP-blocking workflow can combine a threat feed or finding, EventBridge routing, automation such as Lambda, and an enforcement layer such as an AWS WAF IP set.
- EC2 applications should use an instance profile and role instead of static access keys in user data or on disk.
- EventBridge can match an EC2 state-change event; Amazon SNS can fan out email notifications. CloudTrail is required when the workflow depends on a recorded API call rather than a native service event.
- `AssumeRole` is the standard STS operation for a trusted principal to obtain a role session. Web identity and SAML federation use their applicable federation flows.
- Imported KMS key material is rotated by importing new material under the supported import/rotation workflow; do not confuse this with automatic rotation behavior for KMS-generated material.

## Exam Decision Guide

| Clue | Control | Key Reason |
| --- | --- | --- |
| Deny known IPs before CloudFront reaches the origin | AWS WAF web ACL and IP set | Layer 7 edge enforcement. |
| Allow return traffic automatically | Security group | Stateful behavior. |
| Explicitly deny at subnet boundary | Network ACL | Supports deny rules and applies to the subnet. |
| EC2 workload needs S3 | Instance profile containing an IAM role | Temporary credentials without embedded keys. |
| Notify administrators of an EC2 state change | EventBridge plus SNS | Event matching and notification delivery are separate roles. |

## Common Exam Traps

- Security groups have no explicit-deny rules.
- A NACL rule that allows the request but not the response fails because NACLs are stateless.
- SSE-C is server-side encryption even though the customer supplies the key.
- User data is not a safe location for long-term AWS access keys.
- A logging service does not automatically notify or remediate.

## Memory Hooks

> **Detect, route, respond, enforce—and know which service owns each verb.**

## Quick Review

- Use SCPs as organization guardrails for member accounts.
- Pair viewer authorization with origin restriction for private CloudFront content.
- Distinguish stateful security groups from stateless NACLs.
- Use workload roles instead of static credentials.
- Compose event-driven security from producer, router, target, and enforcement control.
- Treat KMS key origin as a clue to supported rotation behavior.

## Self-Check Questions

1. Can an SCP restrict the root user of a member account?

<details><summary>Answer</summary>

Yes. It limits available permissions in member accounts, including their root users, but it does not apply to the organization management account.

</details>

2. What is missing if EventBridge detects a state change but nobody receives email?

<details><summary>Answer</summary>

A notification target such as an Amazon SNS topic with confirmed subscriptions, plus the required target permissions.

</details>

3. Why is an instance role safer than access keys in user data?

<details><summary>Answer</summary>

The role supplies automatically rotated temporary credentials and avoids embedding long-term secrets in instance configuration.

</details>
