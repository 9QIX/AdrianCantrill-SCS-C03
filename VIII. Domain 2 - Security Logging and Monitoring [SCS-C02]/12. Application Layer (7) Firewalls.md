# Layer 7 Application Firewalls

## Overview

A Layer 7 firewall understands application protocol semantics, allowing inspection of fields such as HTTP methods, paths, headers, query strings, bodies, and host names. This enables controls that network-layer address and port filters cannot express.

## Exam Alignment

- **Primary SCS-C03 Domain:** Infrastructure Security
- **Secondary Domain(s):** Detection
- **Main AWS Services:** AWS WAF, AWS Network Firewall, Elastic Load Balancing
- **Lesson Type:** Concept
- **Exam Importance:** High
- **Core Skill:** Select application-aware inspection instead of relying on Layer 3/4 controls for web threats.

## Core Concepts

- Security groups and network ACLs primarily filter network/transport attributes; they do not inspect HTTP semantics.
- AWS WAF evaluates HTTP(S) requests for supported protected resources.
- TLS termination determines where plaintext request elements become available for inspection.
- Rules can block, allow, count, challenge, CAPTCHA, label, or rate-limit matching requests depending on feature and rule configuration.
- Layer 7 visibility creates privacy, logging, latency, and false-positive considerations.

## Exam Decision Guide

| Requirement | Control | Why |
| --- | --- | --- |
| Filter SQL injection or malicious HTTP path | AWS WAF | Inspects supported HTTP request components |
| Stateful VPC traffic inspection across network paths | AWS Network Firewall | Managed network firewall for routed VPC traffic |
| Allow TCP 443 from a CIDR | Security group | Stateful Layer 3/4 resource-level filtering |
| Absorb volumetric DDoS attacks with enhanced support | AWS Shield Advanced | DDoS protection and response features |

## Common Exam Traps

- HTTPS traffic is not magically visible to every inline network device; inspection depends on architecture and termination.
- A web application firewall does not patch vulnerable application code.
- Security groups cannot match URLs or HTTP headers.

## Memory Hooks

> **Ports are Layer 4; requests are Layer 7.**

## Quick Review

- Match control layer to threat layer.
- Place inspection where protocol data is visible.
- Test rules in count mode where appropriate.
- Protect logs containing request data.
- Combine Layer 7 and network controls.

## Self-Check Questions

1. Which control can match an HTTP query string?

<details><summary>Answer</summary>

An application-aware control such as AWS WAF, not a security group or network ACL.

</details>
