# AWS Glue Data Integration and Cataloging

## Overview

AWS Glue is a serverless data-integration service for discovering, cataloging, preparing, moving, and transforming data. For security analytics, its Data Catalog describes log data in Amazon S3 so services such as Athena can query it.

## Exam Alignment

- **Primary SCS-C03 Domain:** Detection
- **Secondary Domain(s):** Incident Response
- **Main AWS Services:** AWS Glue, Amazon S3, Amazon Athena, AWS Lake Formation
- **Lesson Type:** Architecture
- **Exam Importance:** Medium
- **Core Skill:** Catalog and transform security data while protecting execution roles, networks, and sensitive outputs.

## Core Concepts

- The Glue Data Catalog is a Regional persistent metadata store of databases, tables, partitions, schemas, and locations.
- Crawlers inspect supported data sources, use classifiers to infer schema, and update catalog metadata.
- Glue jobs perform extract, transform, and load (ETL) or extract, load, and transform (ELT) using managed engines.
- Triggers and workflows coordinate jobs/crawlers; connections provide access to networked data sources.
- Lake Formation adds fine-grained authorization for cataloged data-lake resources.

## Security Implications

- The crawler or job role needs source read, target write, catalog, KMS, and network permissions—but only for intended resources.
- A crawler can expose metadata about sensitive datasets; protect catalog access.
- Transform outputs may duplicate sensitive data and require independent classification, encryption, retention, and access controls.
- Use private networking/endpoints and controlled connections for nonpublic data stores.

## Exam Decision Guide

| Requirement | Service | Why |
| --- | --- | --- |
| Infer S3 log schema | Glue crawler | Discovers schema and populates catalog |
| Run ad hoc SQL over cataloged S3 logs | Athena | Serverless query engine |
| Transform and normalize log data | Glue job | Managed data integration/ETL |
| Fine-grained lake permissions | Lake Formation | Authorization layer over cataloged data |

## Common Exam Traps

- A crawler catalogs metadata; it does not automatically transform source data.
- The Data Catalog stores metadata, not the source dataset.
- Schema inference should be reviewed; it may not match security semantics.
- AWS Data Pipeline is an older service and should not be the default choice for new serverless ETL designs.

## Memory Hooks

> **Crawler discovers, Catalog describes, Glue job transforms, Athena queries, Lake Formation governs.**

## Quick Review

- Catalog is Regional metadata.
- Secure crawler/job roles and connections.
- Validate inferred schemas.
- Protect transformed outputs.
- Use Athena for query and Glue for integration/transformation.

## Self-Check Questions

1. Does a Glue crawler move source log data into the Data Catalog?

<details><summary>Answer</summary>

No. It creates metadata describing the source and its schema.

</details>
