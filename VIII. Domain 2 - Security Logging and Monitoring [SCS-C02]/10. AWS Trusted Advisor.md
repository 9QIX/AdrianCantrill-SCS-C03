# AWS Trusted Advisor Security and Operational Checks

## Overview

AWS Trusted Advisor evaluates accounts against supported AWS best-practice checks. It supplies recommendations across security, cost, performance, fault tolerance, service limits, and operational excellence; availability and refresh behavior vary by support plan and feature.

## Exam Alignment

- **Primary SCS-C03 Domain:** Security Foundations and Governance
- **Secondary Domain(s):** Detection
- **Main AWS Services:** AWS Trusted Advisor, AWS Support, AWS Organizations
- **Lesson Type:** Concept
- **Exam Importance:** Medium
- **Core Skill:** Use advisory findings without mistaking recommendations for enforcement or remediation.

## Core Concepts

- Checks report status and recommended action for supported resource conditions.
- Organization features can centralize eligible checks when prerequisites are met.
- Event integrations can notify on supported changes; a separate workflow must remediate.
- Trusted Advisor complements, rather than replaces, AWS Config, Security Hub, Inspector, and Service Quotas.

## Exam Decision Guide

| Requirement | Service | Why |
| --- | --- | --- |
| Broad AWS best-practice recommendations | Trusted Advisor | Advisory check catalog |
| Evaluate resource configuration against rules | AWS Config | Configuration history and compliance |
| Continuous EC2/ECR/Lambda vulnerability findings | Inspector | Vulnerability management |
| Enforce organization-wide permission ceiling | SCP | Preventive authorization guardrail |

## Common Exam Traps

- Trusted Advisor recommends; it usually does not block or repair.
- Check availability is not identical across all support plans.
- A successful check is not evidence that every resource or threat was assessed.

## Memory Hooks

> **Advisor recommends; Config evaluates; policies prevent; automation remediates.**

## Quick Review

- Confirm check eligibility and freshness.
- Assign owners to findings.
- Use organization aggregation where supported.
- Add notification/remediation workflows explicitly.
- Do not treat a check catalog as a full audit.

## Self-Check Questions

1. Does Trusted Advisor enforce a security-group recommendation?

<details><summary>Answer</summary>

No. It reports the condition; prevention or remediation requires another control.

</details>
