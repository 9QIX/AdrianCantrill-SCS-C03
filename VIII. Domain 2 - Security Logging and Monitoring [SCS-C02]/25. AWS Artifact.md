# AWS Artifact Compliance Reports and Agreements

## Overview

AWS Artifact is a self-service portal for downloading AWS and eligible third-party security/compliance documents and for reviewing, accepting, and tracking certain AWS agreements. It supplies audit artifacts about AWS controls; customers remain responsible for evidence about their own configurations and controls.

## Exam Alignment

- **Primary SCS-C03 Domain:** Security Foundations and Governance
- **Secondary Domain(s):** None
- **Main AWS Services:** AWS Artifact, AWS Organizations, AWS CloudTrail
- **Lesson Type:** Text-Based Reference
- **Exam Importance:** Medium
- **Core Skill:** Select Artifact for provider compliance reports and agreements without confusing it with continuous compliance monitoring.

## Core Concepts

- Artifact Reports provides on-demand documents such as SOC reports and certifications related to standards including ISO and PCI.
- Artifact Agreements supports account-level and eligible organization-level agreement management.
- Access is controlled by IAM and documents can contain confidential information subject to their terms.
- CloudTrail can record supported Artifact API activity for accountability.
- Artifact documents help due diligence and audits but do not assess whether a customer's workload is compliant.
- Artifact Assurance Assistant can help produce responses to compliance and due-diligence questions; its outputs still require authorized review.

## Exam Decision Guide

| Requirement | Service | Why |
| --- | --- | --- |
| Download AWS SOC/ISO/PCI documents | AWS Artifact Reports | On-demand provider audit artifacts |
| Accept or track eligible AWS agreements | AWS Artifact Agreements | Agreement workflow |
| Continuously evaluate resource configuration | AWS Config | Customer-resource configuration evidence |
| View security posture/finding aggregation | AWS Security Hub | Security findings and standards controls |

## Common Exam Traps

- Artifact is not a scanner, log service, or automatic compliance engine.
- AWS compliance does not automatically make a customer's workload compliant.
- Report-sharing restrictions and confidentiality terms still apply.
- Organization agreement authority should be tightly restricted.

## Memory Hooks

> **Artifact provides AWS evidence and agreements; Config and Security Hub assess your environment.**

## Quick Review

- Use Reports for audit documents.
- Use Agreements for supported legal agreements.
- Restrict access and handle documents securely.
- Record agreement actions.
- Supply separate evidence for customer responsibilities.

## Self-Check Questions

1. Can an AWS Artifact report prove that a customer's S3 bucket is configured compliantly?

<details><summary>Answer</summary>

No. It documents AWS controls and certifications; customer-resource evidence must come from the customer's configuration, logs, and control assessments.

</details>
