# AWS WAF Web ACLs, Rule Groups, and Rules

## Overview

AWS WAF protects supported web applications and APIs by evaluating HTTP(S) requests against ordered rules in a web access control list (web ACL). It can use AWS Managed Rules, vendor-managed groups, or custom rules to block, allow, count, CAPTCHA, challenge, label, and rate-limit requests.

## Exam Alignment

- **Primary SCS-C03 Domain:** Infrastructure Security
- **Secondary Domain(s):** Detection
- **Main AWS Services:** AWS WAF, AWS Firewall Manager, AWS Shield Advanced, Amazon CloudWatch
- **Lesson Type:** Architecture
- **Exam Importance:** High
- **Core Skill:** Build and centrally govern layered web-request controls while monitoring false positives.

## Core Concepts

- Associate a web ACL with supported resources such as CloudFront distributions, Application Load Balancers, API Gateway REST APIs, and other documented integrations.
- Rules run by priority. A terminating action stops evaluation; count and labels can support testing and later matching.
- Rule groups are reusable rule collections. Web ACL capacity units (WCUs) limit combined inspection complexity.
- Managed rule groups reduce maintenance but require version, override, exception, and false-positive management.
- Scope-down statements narrow managed or rate-based rule evaluation.

## Detection, Logging, and Evidence

Enable WAF logging to a supported destination and use sampled requests/metrics for tuning. Protect logs because headers, URIs, and bodies may contain sensitive data; configure redaction where appropriate. AWS Firewall Manager centrally applies WAF policies across eligible organization accounts and resources.

## Troubleshooting

| Symptom | Likely Cause | Verification | Resolution |
| --- | --- | --- | --- |
| Legitimate requests blocked | Managed/custom rule false positive | Inspect terminating rule, labels, sampled request, and logs | Add narrow exception or override after testing |
| Malicious request allowed | Web ACL not associated or rule scope mismatch | Check association and matching fields | Associate correct ACL and refine rule |
| Rule cannot be added | WCU limit exceeded | Review capacity calculations | Reduce complexity or request appropriate capacity design |

## Common Exam Traps

- WAF is for supported web traffic, not arbitrary VPC protocols.
- Shield protects against DDoS; WAF applies application request rules. They complement each other.
- A default `Allow` requires blocking rules; a default `Block` requires complete allow logic.
- `Count` observes but does not block.

## Memory Hooks

> **Web ACL orders policy; rule groups reuse policy; rules inspect requests; Firewall Manager scales policy.**

## Quick Review

- Associate the ACL with the correct resource/scope.
- Order rules deliberately.
- Test changes with count/overrides.
- Watch WCU capacity and managed-rule versions.
- Enable protected logging and central management where required.

## Self-Check Questions

1. What is the safest initial action when evaluating a potentially noisy managed rule?

<details><summary>Answer</summary>

Use count or an appropriate rule-action override, inspect logs and sampled requests, then enforce after tuning.

</details>
