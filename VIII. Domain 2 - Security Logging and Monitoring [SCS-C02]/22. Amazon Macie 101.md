# Amazon Macie Sensitive Data Discovery

## Overview

Amazon Macie is a managed data-security service that inventories Amazon S3 general purpose buckets, evaluates security/access posture, and uses managed and custom data identifiers to discover sensitive data in supported S3 objects.

## Exam Alignment

- **Primary SCS-C03 Domain:** Detection
- **Secondary Domain(s):** Data Protection
- **Main AWS Services:** Amazon Macie, Amazon S3, AWS Organizations, AWS Security Hub, Amazon EventBridge
- **Lesson Type:** Architecture
- **Exam Importance:** High
- **Core Skill:** Discover sensitive S3 data and distinguish sampled automated discovery, targeted jobs, policy findings, and discovery results.

## Core Concepts

- Macie is Regional. An administrator account can manage associated member accounts through AWS Organizations or invitations.
- Automated sensitive data discovery evaluates inventory daily and samples representative eligible objects for broad visibility.
- Sensitive data discovery jobs analyze explicitly selected S3 scope and can be scheduled.
- Managed data identifiers detect common credentials, financial, personal, and health information. Custom identifiers add regex, keywords, proximity, and ignore-word logic for organization-specific data.
- Allow lists suppress known benign text/patterns.
- Policy findings report risky bucket security/access changes; sensitive-data findings report detected sensitive content.

## Detection, Logging, and Evidence

Findings use AWS Security Finding Format (ASFF) for integrations such as Security Hub and EventBridge. Detailed sensitive data discovery results should be exported to a protected S3 repository for retention beyond Macie's 90-day availability. Coverage gaps can result from unsupported formats/storage classes, restrictive bucket policies, or inaccessible KMS keys.

## Common Exam Traps

- Automated discovery samples; it does not guarantee exhaustive inspection of every object.
- Macie focuses on S3 data, not general databases or EC2 filesystems.
- A finding detects risk; it does not automatically encrypt, move, or delete data.
- Bucket sensitivity scores do not define business criticality.

## Memory Hooks

> **Macie inventories S3, discovers sensitive data, and reports policy risk; another workflow remediates.**

## Quick Review

- Enable Macie per required Region.
- Choose automated discovery for breadth and jobs for defined scope.
- Use managed/custom identifiers and allow lists carefully.
- Export detailed results for long-term retention.
- Monitor coverage and KMS/bucket-policy blockers.

## Self-Check Questions

1. Does automated discovery scan every S3 object every day?

No. It evaluates inventory daily and uses sampling to analyze representative eligible objects.
